# 🍁 Maple Boss Tracker (메이플 주간보스 트래커)

메이플스토리 주간/월간 보스 **결정석 수익**을 캐릭터별로 관리하는 Windows 데스크톱 앱입니다.

> 이 저장소는 **설치 파일 배포 전용**입니다. (프로그램 소스코드는 비공개)

## ⬇️ 다운로드 & 설치

1. **[▶ 최신 버전 다운로드](https://github.com/BaeYam/maple-boss-tracker-releases/releases/latest)** 페이지로 이동
2. `MapleBossTracker-Setup-x.x.x.exe` 를 눌러 다운로드
3. 받은 파일을 실행 → **자동으로 설치되고 바로 실행**됩니다
   (사용자 전용 설치라 **관리자 권한 필요 없음**)

### ⚠️ "Windows의 PC 보호"(SmartScreen) 경고가 뜨면
서명되지 않은 개인 앱이라 뜨는 **정상 경고**입니다.
**추가 정보** → **실행** 을 누르면 설치됩니다.

## 🔄 자동 업데이트
설치 후에는 앱을 켤 때마다 **자동으로 최신 버전을 확인**합니다.
새 버전이 있으면 백그라운드로 받아서, 앱 상단에 뜨는 **[지금 재시작]** 버튼을 누르면
마법사 없이 조용히 적용됩니다. (직접 다시 설치할 필요 없음)

## ✨ 주요 기능
- 캐릭터별 주간/월간 보스 12마리 관리 + **결정석 예상 수익** 계산
- 결정석 판매 한도(서버당 주 12마리) 추적
- 사냥 기록 / 누적 통계 / 주간 히스토리 차트
- 넥슨 OpenAPI 연동: 캐릭터 이미지·직업·레벨·**전투력** 자동 갱신
- 미니(플로팅) 모드, 파티 분배 정산기, 리셋 알림

## 💾 데이터 & 백업
기록은 `%APPDATA%\Maple Boss Tracker\boss_tracker_data.json` 에 저장됩니다.
**업데이트/재설치해도 데이터는 그대로 유지**됩니다.
설정 ⚙️ → **데이터 내보내기/가져오기** 로 직접 백업할 수도 있습니다.

## 🔑 넥슨 API 키 (선택)
캐릭터 자동 조회(이미지·직업·레벨·전투력)를 쓰려면
[넥슨 오픈API](https://openapi.nexon.com/ko/) 에서 API 키를 발급받아 설정 ⚙️ 에 입력하세요.
